# Leko Reader

欢迎使用 Leko Reader。

它是 Kindle 第三方阅读器里的网络小说插件，有自己的书架、搜书、目录和阅读界面，也可以缓存全书并导出 TXT、EPUB 或 MOBI。

## 开始前，先看一眼 Kindle

用数据线把 Kindle 连接到电脑，打开 Kindle 磁盘。

如果里面已经有一个名为 `koreader` 的文件夹，就可以继续安装 Leko。这里的 KOReader，就是大家常说的“Kindle 第三方阅读器”。

如果没有这个文件夹，说明第三方阅读器还没有安装好。Leko 需要在 KOReader 里面运行，所以要先完成 KOReader 的安装。

联网搜书还需要一份你自己的书源。没有书源也没关系，Leko 书架会自带一本《欢迎来到 Leko》，可以先熟悉所有主要功能。

## 安装 Leko

### 1. 解压下载的 ZIP

下载的文件名类似：

`Leko-Reader-KOReader-0.15.37.zip`

在电脑上解压后，会得到一个名为 `leko.koplugin` 的文件夹。打开这个文件夹，应该能直接看到 `main.lua` 和 `Leko` 文件夹。

如果解压后看到两层同名文件夹，以实际包含 `main.lua` 的那一层为准。

### 2. 复制到 Kindle

依次打开 Kindle 磁盘里的：

`koreader → plugins`

把整个 `leko.koplugin` 文件夹复制进去。

复制完成后，文件位置应该是：

`koreader/plugins/leko.koplugin/main.lua`

`plugins` 文件夹不存在时，可以在 `koreader` 里面新建一个。

### 3. 重启第三方阅读器

在电脑上安全弹出 Kindle，然后完全退出 KOReader，再重新打开。只回到文件列表不会重新加载插件。

### 4. 打开 Leko 书架

进入 KOReader 的文件管理器主界面，顶栏通常会出现 Leko 书架图标，点一下就能打开。

有些 KOReader 版本或 SimpleUI 会调整顶栏。如果没有看到图标，可以打开右上角菜单，在“更多工具”或“插件”中找到 `Leko Reader`。

看到标题为“Leko 书架”的页面，安装就完成了。

如果入口没有出现，可以重新确认两件事：文件是不是位于 `koreader/plugins/leko.koplugin/main.lua`，以及 KOReader 是否已经完全退出并重新启动。

## 第一次打开，从《欢迎来到 Leko》开始

第一次进入 Leko 书架时，会看到一本《欢迎来到 Leko》。它是放在 Kindle 本地的完整使用说明书，不需要 Wi-Fi。

直接打开它，就能一边翻页一边了解书架、书源、搜索、试读、排版、换源、更新、全书缓存、导出和故障排查。它共有九章，可以从目录自由跳转，不必一次读完。

如果这本书能够正常打开、翻页和显示目录，说明 Leko 书架与内置阅读器已经正常工作。

如果想确认联网书源所需的 JavaScript 引擎也能工作，可以运行：

`菜单 → 书源 → 管理书源 → JavaScript 引擎检查`

看到“JavaScript 引擎工作正常”，就可以继续导入书源和搜书。

## 准备联网搜书

### 书源是什么？

书源可以理解成一份“网站使用说明”。它告诉 Leko 去哪里搜索、哪里是书名和作者、怎样找到目录，以及怎样取得章节正文。

书源通常是一份 `.json` 文件，也可能是一个导入网址。Leko 的安装包不预装网络书源，网络书源由用户自行配置。

### 用手机导入（推荐）

不想在 Kindle 上输入长网址时，可以直接用手机发送书源：

1. 让 Kindle 和手机连接同一个 Wi-Fi。
2. 打开 `Leko 书架 → 菜单 → 书源 → 用手机导入`。
3. 用手机扫描 Kindle 上的二维码。
4. 在手机页面粘贴书源网址、粘贴书源 JSON 内容，或选择本地 `.json` 文件。
5. Kindle 会显示下载、解析和保存进度；完成后，手机页面可以继续发送下一份书源，不必重新扫码。

手机页面只在 Kindle 的临时地址上工作，不需要第三方二维码网站，也不会把书源发送到 Leko 之外的服务。

### 备用：导入 JSON 文件

1. 把书源 JSON 文件复制到 Kindle。
2. 打开 `Leko 书架 → 菜单 → 书源`。
3. 选择“从文件导入”。
4. 找到刚才复制的文件，确认导入。

### 备用：使用导入网址

1. 让 Kindle 连上 Wi-Fi。
2. 打开 `Leko 书架 → 菜单 → 书源`。
3. 选择“通过网址导入”。
4. 输入完整网址，点“导入”。

导入完成后回到书架，打开右上角菜单，选择“查找书籍”，输入书名即可。

## 搜索结果怎样用

搜索开始后，结果会陆续出现，不需要等全部书源完成。

打开一本书时，Leko 会继续取得书籍详情、目录和第一章，所以会比刚看到搜索结果多等一会儿。进入正文后可以直接试读，退出时再选择：

- “加入书架并退出”：把书留下，以后从 Leko 书架继续读；
- “仅退出”：这次只试读，不加入书架；
- “继续阅读”：回到刚才的正文。

## 阅读时常用的功能

### 调整排版

阅读正文时点“排版”，可以调整字号、行距、页边距、段间距和首行缩进。设置会立即应用，不需要重新打开书籍。

### 打开目录

点正文顶部的“目录”，可以翻页浏览完整目录，也可以按章节序号跳转。

### 换一个正文来源

打开“书籍详情”，选择“书籍换源”。当某个来源缺章、乱码、正文错误或访问较慢时，可以换另一条书源继续读。

“封面换源”只更换封面，不会改变正文来源。

### 检查新章节

打开 `书籍详情 → 更多 → 刷新目录与书籍信息`。

Leko 默认由用户手动检查更新，这样平时阅读和待机时不会为了查更新反复联网。

### 重新读取当前章

正文异常时，可以点阅读页的“刷新本章”，重新下载这一章。

## 缓存全书和导出

打开 `书籍详情 → 更多`，可以开始或暂停全书缓存。Leko 会按章节下载，并保留已经完成的进度。

全书缓存完成后，可以导出：

- **TXT**：最简单，兼容范围很广；
- **EPUB**：带封面、目录和电子书排版；
- **MOBI**：适合放进较老 Kindle 的原生书库。

导出 MOBI 时，默认选择 Kindle 的 `documents` 根目录，完成后更容易被原生书库发现。导出位置可以在 `Leko 书架 → 菜单 → 导出设置` 中修改。

导出时还会显示一次章节进度，因为插件需要把缓存逐章读取并转换成目标格式。这一阶段通常不再重新下载正文。

## 管理书源

打开 `菜单 → 书源 → 管理书源`，可以查看所有已导入书源。

长按一条书源，可以把它放到优先搜索、自动排序或搜索末尾，也可以启用、停用、删除和检查连通性。

“可使用”表示 Leko 认识这条书源所需的功能；网站当时能否连接、书源是否仍然有效，还要看实际搜索结果。

每次导入书源时，Leko 都会保留一份原始备份。需要找回时，打开 `菜单 → 书源 → 从备份恢复`，按日期选择即可；也可以从 `存储与缓存 → 书源备份` 进入。恢复会添加或更新备份中的书源，不会删除其他现有书源。

如果误删了本地的《欢迎来到 Leko》，可以在书源菜单中选择“把欢迎书放回书架”。这个操作只重新生成本地欢迎书，不会改动已经导入的网络书源。

## 查看和清理存储空间

打开 `菜单 → 存储与缓存`，可以查看搜索缓存、详情与目录缓存、图片缓存、临时下载和已下载章节分别占用了多少空间。

搜索、详情和图片缓存可以在需要时重新生成；已下载章节用于离线阅读和导出，属于书籍数据。

## 遇到问题时

可以按这个顺序检查：

1. 打开书架中的《欢迎来到 Leko》，确认目录和正文可以显示。
2. 运行“JavaScript 引擎检查”。
3. 用另一条书源搜索同一本书。
4. 检查 Kindle 的 Wi-Fi、日期和时间。
5. 打开 `存储与缓存 → 最近一次错误` 查看原因。

如果《欢迎来到 Leko》可以正常阅读，只有某条网络书源失败，通常与那条书源或网站当前状态有关。如果欢迎书也无法打开，可以先检查安装路径、KOReader 版本和“最近一次错误”。

## 升级 Leko

1. 完全退出 KOReader。
2. 备份旧的 `leko.koplugin` 文件夹，并把它移出 `plugins`。
3. 把新版 `leko.koplugin` 复制进去。
4. 重新打开 KOReader。

普通升级会保留 Leko 的书架、书源、阅读位置和书源排序设置。

## 项目说明

Leko Reader 是独立实现，与 Legado、KOReader、书源维护者及内容网站均无隶属或背书关系。它专注于普通网页的规则解析与阅读，不包含浏览器交互和受限内容访问功能。

仓库和安装包不预装网络书源合集，内置内容只用于离线自检。网络书源由用户自行配置和管理。

Leko 没有遥测、广告或项目自建的中转服务器。书架、阅读位置、缓存章节、封面、书源和设置保存在设备本地；导入的网络书源会按照自身规则访问相应网站并维护网络会话。诊断记录也保存在本地，卸载插件不会自动删除导出文件和 KOReader 数据目录中的缓存。

## 开发者信息

普通用户可以直接忽略这一节。

生成安装 ZIP：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

验证字符编码表：

```powershell
python .\scripts\generate_charset_tables.py --check
```

插件源码位于 `leko.koplugin/`，QuickJS bridge 源码和构建脚本位于 `native/bridge/`，已打包二进制的设备 ABI 记录在 `leko.koplugin/Leko/native/ABI.md`。
